คลังความรู้ทางคณิตศาสตร์และสูตรมาตรฐานสำหรับคำนวณพาราโบลาที่มีแกนสมมาตรขนานกับแกน Y

สมการมาตรฐาน (Standard Form)

(x - h)² = 4c(y - k)

เมื่อ (h, k) คือพิกัดจุดยอด และ c คือระยะทางกำกับจากจุดยอดไปยังโฟกัส

ลักษณะของกราฟพาราโบลา

  • c > 0 พาราโบลาหงาย: โค้งเปิดขึ้นด้านบน จุดยอดเป็นจุดต่ำสุดของกราฟ
  • c < 0 พาราโบลาคว่ำ: โค้งเปิดลงด้านล่าง จุดยอดเป็นจุดสูงสุดของกราฟ

องค์ประกอบเชิงเรขาคณิต

จุดยอด (Vertex)

พิกัด (h, k) จุดเปลี่ยนทิศทางความโค้ง

จุดโฟกัส (Focus)

พิกัด (h, k + c) อยู่ภายในส่วนโค้ง

เส้นไดเรกตริกซ์ (Directrix)

เส้นตรง y = k - c ตั้งฉากกับแกนสมมาตร

แกนสมมาตร (Axis)

เส้นตรง x = h แบ่งครึ่งกราฟสมมาตร
